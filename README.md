# INAP QCM

Quiz d'entraînement au tronc commun INAP : PGP, DOAP, CGE et CCC.

La banque source contient **100 QCM** (25 par matière), reconstruits à partir des **4 nouvelles synthèses Word** et contrôlés avec les **4 supports PDF** fournis.

Chaque test utilise désormais **80 QCM : 20 PGP, 20 DOAP, 20 CGE et 20 CCC**. Les 20 questions sont sélectionnées dans la banque de chaque matière.

Le site conserve le mode entraînement avec correction immédiate, le suivi de progression et un **mode examen de 2 heures (120 minutes)** sans correction immédiate.
